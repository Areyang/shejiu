<Note>
  Shejiu is built on a **Java Spring Boot** backend (MyBatis + Maven) paired with a **Vue 2** (Options API) frontend powered by Element UI and ECharts for data visualization. All persistent data is stored in **ADB MySQL columnar storage**, which delivers fast analytical reads across large datasets. Be aware that ADB MySQL does not support triggers, stored procedures, composite indexes, correlated sub-queries, or CTEs — keep these constraints in mind when extending the platform or writing custom queries.
</Note>
